# Diagnostic rules catalog

This catalog is the user-facing contract for CSV Import Doctor diagnostics. `ruleId` values are stable identifiers for reports and tests. Each emitted issue also carries a severity, category, explanation, and repair safety. Product-profile issues include the versioned profile and official source URL. Parser issues use category `parser`; row numbers are logical CSV records with the header at row 1. A newline inside a quoted field does not increment the logical record number.

Categories:

- `parser`: file structure, encoding, delimiter, or record-shape checks.
- `shopify-profile`: a documented format constraint or dependency.
- `recommendation`: a risk or advisory that depends on import choices or store state.

## Parser rules

| Rule ID | Severity | What it means and what to do |
| --- | --- | --- |
| `file-too-large` | error | File exceeds the configured local character limit; split it while retaining its header row. |
| `row-limit-exceeded` | error | File exceeds the configured data-row limit; split it into smaller CSVs, each with its own header. |
| `file-empty` | error | No usable header row was found. |
| `delimiter-ambiguous` | warning | Several separators produce plausible tables; confirm the actual delimiter before relying on row and column diagnostics. |
| `duplicate-header` | error | Two columns have the same header; rename or remove the duplicate. IDs include the duplicate's column position to remain unique. |
| `column-count-mismatch` | error | A logical record has a different field count from the header; review quoting and separators at the reported row. |
| `parser-<Papa Parse error code>` | error | CSV syntax could not be read reliably; review quoting and escaped quotes at the reported logical record. |

Parser issues do not claim Shopify compatibility and do not link to a Shopify profile source.
